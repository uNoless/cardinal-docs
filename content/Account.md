
## Архитектурная роль
Модуль **account** предоставляет класс **Account**, который управляет взаимодействием с API FunPay. Он отвечает за авторизацию, получение данных об аккаунте, отправку сообщений, обработку заказов и другие операции с аккаунтом.

## Компоненты и логика

### `Account`
* **Назначение:** Класс для управления аккаунтом FunPay.
* **Аргументы и связи:**
 * **golden_key** (`str`): Токен аккаунта.
 * **user_agent** (`str | None`): User-agent браузера.
 * **requests_timeout** (`int | float`): Тайм-аут запросов.
 * **proxy** (`dict | None`): Прокси для запросов.
 * **locale** (`Literal['ru', 'en', 'uk'] | None`): Язык аккаунта.

* **Назначение:** Инициализирует экземпляр класса **Account**.
