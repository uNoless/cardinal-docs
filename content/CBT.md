
## Архитектурная роль
Модуль **CBT** содержит набор констант, которые используются для управления различными аспектами работы системы FunPayCardinal. Эти константы определяют идентификаторы команд, настройки, пути и другие параметры, необходимые для корректной работы системы.

## Компоненты и логика
### Константы
* **MAIN**: Основная константа, используемая для идентификации основного режима работы.
* **CATEGORY**: Константа для идентификации команды, связанной с категориями.
* **SWITCH**: Константа для переключения между различными режимами или настройками.
* **ADD_CMD**: Константа для добавления новой команды.
* **CMD_LIST**: Константа для получения списка доступных команд.
* **EDIT_CMD**: Константа для редактирования существующей команды.
* **EDIT_CMD_RESPONSE_TEXT**: Константа для редактирования текста ответа команды.
* **EDIT_CMD_NOTIFICATION_TEXT**: Константа для редактирования текста уведомления команды.
* **SWITCH_CMD_SETTING**: Константа для переключения настроек команды.
* **DEL_CMD**: Константа для удаления команды.
* **FP_LOTS_LIST**: Константа для получения списка лотов FunPay.
* **ADD_AD_TO_LOT**: Константа для добавления объявления в лот.
* **ADD_AD_TO_LOT_MANUALLY**: Константа для добавления объявления в лот вручную.
* **AD_LOTS_LIST**: Константа для получения списка объявлений в лотах.
* **EDIT_AD_LOT**: Константа для редактирования лота с объявлениями.
* **EDIT_LOT_DELIVERY_TEXT**: Константа для редактирования текста доставки лота.
* **BIND_PRODUCTS_FILE**: Константа для привязки файла с продуктами.
* **DEL_AD_LOT**: Константа для удаления лота с объявлениями.
* **PRODUCTS_FILES_LIST**: Константа для получения списка файлов с продуктами.
* **EDIT_PRODUCTS_FILE**: Константа для редактирования файла с продуктами.
* **UPLOAD_PRODUCTS_FILE**: Константа для загрузки файла с продуктами.
* **CREATE_PRODUCTS_FILE**: Константа для создания нового файла с продуктами.
* **ADD_PRODUCTS_TO_FILE**: Константа для добавления продуктов в файл.
* **DOWNLOAD_CFG**: Константа для загрузки конфигурации.
* **TMPLT_LIST**: Константа для получения списка шаблонов.
* **TMPLT_LIST_ANS_MODE**: Константа для получения списка шаблонов в режиме ответов.
* **EDIT_TMPLT**: Константа для редактирования шаблона.
* **DEL_TMPLT**: Константа для удаления шаблона.
* **ADD_TMPLT**: Константа для добавления нового шаблона.
* **SEND_TMPLT**: Константа для отправки шаблона.
* **SWITCH_TG_NOTIFICATIONS**: Константа для переключения уведомлений Telegram.
* **REQUEST_REFUND**: Константа для запроса возврата.
* **REFUND_CONFIRMED**: Константа для подтверждения возврата.
* **REFUND_CANCELLED**: Константа для отмены возврата.
* **BAN**: Константа для бан-листа.
* **UNBAN**: Константа для разбана.
* **SHUT_DOWN**: Константа для выключения системы.
* **CANCEL_SHUTTING_DOWN**: Константа для отмены выключения системы.
* **SEND_FP_MESSAGE**: Константа для отправки сообщения в FunPay.
* **UPLOAD_CHAT_IMAGE**: Константа для загрузки изображения чата.
* **UPLOAD_OFFER_IMAGE**: Константа для загрузки изображения предложения.
* **UPLOAD_BACKUP**: Константа для загрузки резервной копии.
* **UPDATE_PROFILE**: Константа для обновления профиля.
* **MANUAL_AD_TEST**: Константа для тестирования объявления вручную.
* **CLEAR_STATE**: Константа для очистки состояния.
* **BACK_TO_REPLY_KB**: Константа для возврата к клавиатуре ответа.
* **BACK_TO_ORDER_KB**: Константа для возврата к клавиатуре заказа.
* **PLUGINS_LIST**: Константа для получения списка плагинов.
* **EDIT_PLUGIN**: Константа для редактирования плагина.
* **TOGGLE_PLUGIN**: Константа для переключения плагина.
* **PLUGIN_SETTINGS**: Константа для настроек плагина.
* **PLUGIN_COMMANDS**: Константа для команд плагина.
* **DELETE_PLUGIN**: Константа для удаления плагина.
* **CANCEL_DELETE_PLUGIN**: Константа для отмены удаления плагина.
* **CONFIRM_DELETE_PLUGIN**: Константа для подтверждения удаления плагина.
* **UPLOAD_PLUGIN**: Константа для загрузки плагина.
* **PARAM_DISABLED**: Константа для отключения параметра.
* **MAIN2**: Дополнительная константа для основного режима работы.
* **EDIT_GREETINGS_TEXT**: Константа для редактирования текста приветствия.
* **EDIT_ORDER_CONFIRM_REPLY_TEXT**: Константа для редактирования текста ответа на подтверждение заказа.
* **SEND_REVIEW_REPLY_TEXT**: Константа для отправки текста ответа на отзыв.
* **EDIT_REVIEW_REPLY_TEXT**: Константа для редактирования текста ответа на отзыв.
* **EDIT_WATERMARK**: Константа для редактирования водяного знака.
* **EXTEND_CHAT**: Константа для продления чата.
* **OLD_MOD_HELP**: Константа для помощи старого мода.
* **EMPTY**: Константа для пустого значения.
* **LANG**: Константа для языка.
* **EDIT_GREETINGS_COOLDOWN**: Константа для редактирования таймаута приветствия.
* **CHANGE_GOLDEN_KEY**: Константа для изменения золотого ключа.
* **CONFIG_LOADER**: Константа для загрузки конфигурации.
* **AUTHORIZED_USERS**: Константа для авторизованных пользователей.
* **AUTHORIZED_USER_SETTINGS**: Константа для настроек авторизованных пользователей.
* **PROXY**: Константа для прокси.
* **ADD_PROXY**: Константа для добавления прокси.
* **CHOOSE_PROXY**: Константа для выбора прокси.
* **DELETE_PROXY**: Константа для удаления прокси.
* **PIN_PLUGIN**: Константа для закрепления плагина.
