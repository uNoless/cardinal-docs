
## Архитектурная роль
Модуль **enums** содержит перечисления (Enum), которые используются для стандартизации и упрощения работы с различными типами данных и событиями в системе FunPayCardinal. Эти перечисления помогают уменьшить вероятность ошибок и улучшают читаемость кода.

## Компоненты и логика

### `EventTypes`
* **Назначение:** Перечисление для типов событий, которые могут возникнуть в системе FunPayCardinal.
* **Взаимодействие:** Используется в классе [[Events#BaseEvent|BaseEvent]] для идентификации типа события.

### `MessageTypes`
* **Назначение:** Перечисление для типов сообщений, которые могут поступать в систему FunPayCardinal.
* **Взаимодействие:** Используется в классе [[Events#NewMessageEvent|NewMessageEvent]] для идентификации типа сообщения.

### `OrderStatuses`
* **Назначение:** Перечисление для состояний заказов, которые могут быть в системе FunPayCardinal.
* **Взаимодействие:** Используется в классе [[Types#Order|Order]] для идентификации состояния заказа.

### `SubCategoryTypes`
* **Назначение:** Перечисление для типов подкатегорий, которые могут быть в системе FunPayCardinal.
* **Взаимодействие:** Используется в классе [[Types#SubCategory|SubCategory]] для идентификации типа подкатегории.

### `Currency`
* **Назначение:** Перечисление для типов валют баланса FunPay.
* **Аргументы и связи:**
 * **code** (`str`): Код валюты.
* **Взаимодействие:** Используется в классе [[Types#Balance|Balance]] для идентификации типа валюты.

### `Wallet`
* **Назначение:** Перечисление для кошельков для вывода средств с баланса FunPay.
* **Взаимодействие:** Используется в классе [[Types#PaymentMethod|PaymentMethod]] для идентификации типа кошелька.
