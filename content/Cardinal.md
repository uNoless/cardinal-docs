
## Архитектурная роль
Модуль **cardinal** является центральным компонентом системы FunPayCardinal, отвечающим за инициализацию и управление основными функциями бота, включая взаимодействие с Telegram API, обработку событий и плагинов. Он также обеспечивает доступ к конфигурационным данным и управляет жизненным циклом бота.

## Компоненты и логика
### `get_cardinal()`
* **Назначение:** Возвращает существующий экземпляр кардинала.
* **Аргументы и связи:** 
 * Нет аргументов.
* **Взаимодействие:** Нет.

### `PluginData`
* **Назначение:** Класс, описывающий плагин.
* **Аргументы и связи:** 
 * **name** (`str`): название плагина.
 * **version** (`str`): версия плагина.
 * **desc** (`str`): описание плагина.
 * **credentials** (`str`): авторы плагина.
 * **uuid** (`str`): UUID плагина.
 * **path** (`str`): путь до плагина.
 * **plugin** (`ModuleType`): как модуля.
 * **settings_page** (`bool`): есть ли страница настроек у плагина.
 * **delete_handler** (`Callable` | None): хэндлер, привязанный к удалению плагина.
 * **enabled** (`bool`): включен ли плагин.
 * **pinned** (`bool`): закреплен ли плагин в списке плагинов.
* **Взаимодействие:** Нет.

### `Cardinal`
* **Назначение:** Основной класс, управляющий работой бота.
* **Аргументы и связи:** 
 * **main_config** (): основной конфигурационный файл.
 * **auto_delivery_config** (): конфигурационный файл для авто выдачи.
 * **auto_response_config** (): конфигурационный файл для авто передачи.
 * **raw_auto_response_config** (): сырой конфигурационный файл для авто передачи.
 * **version** (`str`): версия бота.
 -  Экземпляр класса кардинал содержит в себе следующие важные глобальные переменные, которые необходимы для написания плагинов:
  - `BIND_TO_PRE_INIT` – До старта основных подсистем fp api
  - `BIND_TO_INIT` – После полной инициализации fp api, tg bot
  - `BIND_TO_POST_START` – После того как запущен [[Runner]]
  - `BIND_TO_NEW_ORDER` – Как только появляется заказ ([[Events#NewOrderEvent| NewOrderEvent]] )
  - `BIND_TO_ORDER_STATUS_CHANGED` – Как только изменился статус заказа ([[Events#OrderStatusChangedEvent| OrderStatusChangedEvent]])
  - `BIND_TO_NEW_MESSAGE` – Как только пришло сообщение ([[Events#NewMessageEvent| NewMessageEvent]] )
  - `BIND_TO_DELETE` – Удаление плагина через меню в tg bot
* **Взаимодействие:** 
 * Вызывает [[Cardinal#__init_account|__init_account]]
 * Вызывает [[Cardinal#__init_telegram|__init_telegram]]
 * Вызывает [[Cardinal#__update_profile|__update_profile]]
 * Вызывает [[Bot#TGBot|TGBot]]

* **Аргументы и связи:** 
 * **infinite_polling** (`bool`): бесконечно посылать запросы, пока не будет получен ответ (игнорировать макс. кол-во попыток).

 * **update_telegram_profile** (`bool`): обновить информацию о профиле для TG ПУ.
 * **update_main_profile** (`bool`): обновить информацию о профиле для всего кардинала (+ хэндлеров).
* **Взаимодействие:** Нет.

### send_message
* **Назначение:** Отправляет сообщение в чат FunPay.

 * **message_text** (`str`): текст сообщения.
