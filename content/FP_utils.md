
## Архитектурная роль
Модуль **fp_utils** предоставляет набор утилитарных функций и констант для работы с API и внутренней логикой системы FunPay. Он включает в себя функции для парсинга различных форматов данных, таких как даты, валюты и время ожидания, а также генерацию случайных тегов для запросов. Этот модуль также содержит скомпилированные регулярные выражения для обработки системных сообщений и других текстовых элементов.

## Компоненты и логика

### `MONTHS`
* **Назначение:** Константа, содержащая список месяцев на русском языке.
* **Аргументы и связи:** 
* **Взаимодействие:** Используется в функциях для парсинга дат и времени.

### `CURRENCY_MAP`
* **Назначение:** Константа, содержащая карту валют для парсинга.
* **Аргументы и связи:** 
* **Взаимодействие:** Используется в функции **parse_currency**.

### `random_tag`
* **Назначение:** Генерирует случайный тег для запроса.
* **Аргументы и связи:** 
* **Взаимодействие:** Используется в других частях системы для идентификации запросов.

### `parse_wait_time`
* **Назначение:** Парсит ответ FunPay на запрос о поднятии лотов и извлекает примерное время ожидания до следующего поднятия лотов.
* **Аргументы и связи:** 
 * **response** (`str`): текст ответа от FunPay.
* **Взаимодействие:** Вызывается при работе с API для получения информации о времени ожидания.

### `parse_currency`
* **Назначение:** Парсит строку валюты и возвращает соответствующий объект валюты.
* **Аргументы и связи:** 
 * **s** (`str`): строка валюты.
* **Взаимодействие:** Использует константу **CURRENCY_MAP** для парсинга валют.

### `strip_invisible_suffix`
* **Назначение:** Удаляет невидимые суффиксы из текста.
* **Аргументы и связи:** 
 * **text** (`str`): исходный текст.
* **Взаимодействие:** Используется для очистки текстовых данных перед дальнейшей обработкой.

### `parse_funpay_datetime`
* **Назначение:** Парсит строку даты и времени в формате FunPay.
* **Аргументы и связи:** 
 * **date_text** (`str`): строка даты и времени.
* **Взаимодействие:** Используется для парсинга дат и времени из текстовых сообщений.

### `RegularExpressions`
* **Назначение:** Класс, содержащий скомпилированные регулярные выражения для обработки системных сообщений и других текстовых элементов.
* **Аргументы и связи:** 
* **Взаимодействие:** Используется в других частях системы для парсинга текстовых данных.
