
## Архитектурная роль
Модуль **types** содержит набор классов и типов данных, которые используются для представления различных сущностей и структур данных в системе FunPayCardinal. Эти классы обеспечивают структурированный и типизированный подход к работе с данными, полученными из API FunPay.

## Компоненты и логика

* **Назначение:** Базовый класс для представления информации о заказах.

* **Взаимодействие:** Нет.
